# Marca

Logo atual: silhueta chapada em verde (`#106B1F`) com penas em negativo branco, olho vazado e
balão contornado com três pontos.

- `piriquito-logo.svg` / `.png` — marca principal (pássaro + balão), fundo transparente.
- `piriquito-icon.svg` / `.png` — variante para ícone de app (fundo arredondado claro).
- `trace_ref.py` — vetoriza a imagem de referência (potrace) e desenha olho e balão vetoriais.

Versões anteriores, mantidas para referência:
- `piriquito-silhueta.svg` / `piriquito-silhueta-kids.svg` — silhueta traçada da foto com gradientes
  e a variante infantil (`trace_silhueta.py`, `kids_details.py`).
