# Chatito

Mensageiro privado da família — macOS, Windows e Android. Servidor de relay cego (E2E) em Go que
guarda mensagens só até serem entregues.

- `PLAN.md` — plano, arquitetura, fases e orquestração
- `docs/PROTOCOL.md` — contrato cliente ↔ servidor
- `server/` — relay em Go · `app/` — cliente Flutter · `docker/` — imagens e compose · `cron/deploy.sh` — deploy no Oracle
